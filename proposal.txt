Problem Statement:
Financial institutions need to decide whether to approve or reject credit applications while balancing default risk and profitability. This project addresses the problem of accurately predicting credit default and supporting decision-making with interpretable insights.

Application Domain:
FinTech / Credit Risk Analytics (Banking & Financial Services)

Objective:
To build an AI-powered credit risk analysis system that predicts the probability of loan default using the Home Credit Default Risk dataset (Kaggle), and provides decision recommendations (approve/reject/review) along with explainable insights.

Expected Outcome:
The system will output a risk score, business decision, and explanation for each applicant, along with portfolio-level analytics to estimate expected loss and optimize approval strategies.

MLOps Involvement:
The project will implement an end-to-end MLOps pipeline including data ingestion and preprocessing, feature engineering, model training and evaluation, experiment tracking (MLflow), data/model versioning (DVC), API deployment (FastAPI), containerization (Docker), and monitoring (Prometheus + Grafana) to ensure reproducibility, scalability, and maintainability.
